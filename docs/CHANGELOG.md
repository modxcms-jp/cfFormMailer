このプロジェクトは [セマンティックバージョニング](https://semver.org/lang/ja/) に準拠しています。

## [Unreleased]

### Added

- **確認画面でアップロードされたファイルを表示するのに、プラグイン cfFileView が要らなくなった**。確認画面のテンプレートで `[+項目名.url+]` を使うと、スニペットが本人のファイルだけを返す（フォームのページの URL に `?cfm_file=項目名` を付けたもの）。返し方は、`X-Content-Type-Options: nosniff` を付け、画像（SVG を除く）と PDF のほかはダウンロードとして返し、ファイルが無ければ 404（#25）
- **プラグイン cfFileView（`cfFileView?field=項目名`）は使わない**。対応している MODX（evolution-jp 1.2 以降）では、見つからないページの `documentIdentifier` が `0` になるため、このプラグインは以前から働いていなかった（404 になる）。確認画面のテンプレートの `cfFileView?field=項目名` を `[+項目名.url+]` に書き換え、プラグインは削除してよい

### Changed

- **送信メールの文字コードの既定を `utf-8` に変更**（`mail_charset` が未指定・空欄の場合も `utf-8`）。本文に合わせて PHPMailer の `CharSet`・`Encoding` を指定する。JIS で送る場合は `mail_charset = iso-2022-jp` を指定する（#7）
- **ファイルの構成を変更**：入口の `bootstrap.php` は v1.7.0 と同じく設置フォルダの直下に置き、クラスは `src/` に移した（`src/Class_cfFormMailer.php`）。スニペットのコードは v1.7.0 から変えなくてよい。`@FILE:` を設置フォルダ → MODX のルートの順に探すこと、`additionalMethods.inc.php`・`tmp/` を設置フォルダの直下に置くことも v1.7.0 と同じ（#18）
- 同梱のサンプルの確認画面を、1 つのフォームに「送信する」と「戻る」のボタンを置く形にした（#16）
- **アップロードされたファイルの MIME タイプを、PHP の Fileinfo でファイルの中身から判定するようにした**。これまでは画像以外のファイルで、ブラウザが送ってきた種類をそのまま使っていた（`class.upload.php` を置いたときだけ中身から判定していた）。`allowtype` の検証・確認画面の `[+項目.filetype+]`・cfFileView の Content-Type の結果が、ファイルによっては変わる（例：ブラウザが `application/octet-stream` と送ってきた本物の PDF は PDF として扱われ、中身がテキストの `.pdf` は PDF として扱われなくなる）。`class.upload.php` は使わなくなった

### Fixed

- フォームの再表示で、未選択の項目の警告が出る不具合と、`select`・`textarea` の値が戻らない不具合（#8）
- 1 つのファイル項目に複数のファイルが送られたときの検証（#9）
- 存在しない配列キーの読み取りによる Warning・Deprecated（`<iferror.(a,b)>` のグループ指定、送信先の切り替え、`len(5-)`・`range(1~)` の省略形、`zenhan`・`hanzen` の既定値など）（#10）
- テキストフィルタ `num`・`dateformat`・`sprintf` の PHP 8 での TypeError と、`dateformat` の `strftime()` の Deprecated（#11）
- 同梱のサンプル（`forms/sample/config.ini`・`config.with_comment.ini`）のテンプレートのパスが解決できなかった（`@FILE:tpl/...`）。設置フォルダからのパス（`@FILE:forms/sample/...`）に直した
- 送信先の切り替え（`dynamic_send_to_field`）で、`<option value="">選択してください</option>` のように value と sendto のそろわない選択肢があると、警告が 6 つ出ていた（MODX 1.3 系では 500 になる）。v1.3 系と同じく、value と sendto の両方がそろった選択肢だけを使う（#20）
- name に `[]` の無い項目（`email`・`tel` など）に配列（`email[]=…`）が送られると、PHP 8 で TypeError になっていた。入力エラー「入力値の形式が正しくありません」にする（#20）
- **送信（send）で、確認画面から送られてきた値をそのまま使っていた**。確認画面の hidden の値を書き換えて送ると、検証を通らない値（不正なメールアドレス、空の必須項目、配列など）のままメールを送っていた。確認画面を出すときに検証を通った値をセッションに覚えておき、送信ではその値を使う。確認画面を通っていなければ送信しない（#21）
- 管理画面の言語が utf・euc のどちらも含まないとき（`english` など）、言語名を文字コードとして使い、PHP 8 ではすべてのページが ValueError で落ちていた。`utf-8` として扱う（#22）
- `reply_to` を `a+@+b` の形で組むとき、欄が 1 つ空だと `exit()` してページ全体が止まっていた。自動返信先の形式の誤りとして、入力エラーにする（#22）
- 管理者宛のメール本文のエスケープを、`reply_ishtml` で決めていた。v1.3 系と同じく、管理者宛は `admin_ishtml`、自動返信は `reply_ishtml` で決める。`admin_ishtml` と `reply_ishtml` を違う値にしているサイトでは、管理者宛のメール本文が変わる（#22）
- 自動返信の送信者の設定 `reply_from` を読んでいなかった（送信者はいつも管理者のアドレスだった）。`reply_from` を指定しているサイトでは、自動返信の送信者がそのアドレスになる（#22）
- name に `[]` の付いた項目に、文字列を前提にした標準の検証（`num`・`email`・`len`・`tel`・`zip`・`url`・`convert`・`zenhan`・`hanzen`）を付けると、PHP 8 で TypeError になっていた。配列の要素ごとに検証・変換する（#23）
- 入れ子の配列（`items[a][]=…`）が送られると、TypeError や Array to string conversion の警告が出ていた。`name="xxx[]"` の 1 段の配列までを受け、それより深い値は捨てる（#23）
- 正しい管理者のメールアドレスが 1 つも無いとき、警告を出し、宛先も送信者も空のまま「送信完了」になっていた。エラーにしてメールを送らない（#24）
- 設定の値が空の行（`reply_fromname =` など）が、既定値を空で上書きしていた。v1.3 系と同じく、値が空の行は「省略」として扱い、既定値を使う。値を空のまま残している設定では、`reply_fromname`（サイト名）・`admin_mail`（MODX の `emailsender`）・`reply_to`（`email`）・`send_mail`（`1`、メールを送る）などが既定値になる。同梱のサンプルの設定では、自動返信の送信者名がサイト名になる（#28）
- テンプレートの id・name に正規表現の記号（`@` など）があると、警告が出て項目名が取れなかった。あわせて、`name="xxx[]"` の項目にエラーの class が付かなかった（#24）
- 一時ファイルが無いときに、`unlink()` で警告が出ていた（#24）

### Security

- フォームに無いファイルの項目（`$_FILES` にだけあるもの）も保存し、管理者宛のメールに添付していた。`allowtype`・`allowsize` の検証を通らないため、フォームにあるファイルの項目だけを受ける（#24）
- 確認画面でアップロードされたファイルを返すとき、HTML や SVG を、サイトのオリジンでそのまま表示させていた（プラグイン cfFileView の返し方）。`X-Content-Type-Options: nosniff` を付け、画像（SVG を除く）と PDF のほかはダウンロードとして返す。`[+項目名.url+]` はこの返し方を使う（#24・#25）

### Changed

- **ディレクトリ構成の変更**（サンプルファイルを`forms/sample/`へ移動）

## [1.0.0] - 2010-03-06

### Added

- **ファイルを添付しての送信に対応**（環境設定`attach_file`, `attach_file_name`追加）
- **ユーザーからの画像ファイルアップロードと送信に対応**
- **携帯端末宛自動返信メールのテンプレートをPC宛とは独立して設定可能に**
  - 環境設定`tmpl_mail_reply_mobile`追加
- **valid属性の3番目のパラメータを`[+errors+]`表示時の項目名として利用**

### Changed

- **独自検証メソッド、独自フィルターメソッドの追加方法を変更**
  - ※従来の方法もひとまず使用可能ですが、非推奨
- 環境設定`admin_name`の初期値を「サイト名」から未定義に変更
- `class.cfFormMailerMODx.inc.php`を廃し、メインクラス内に統合

### Fixed

- メールの件名と送信者名が文字化けする場合がある不具合に対処
- `<select>`タグ、`<textarea>`タグへ`INVALID_CLASS`を付加する際に余分なスラッシュを付加してしまう問題を修正
- サンプルテンプレートでのID重複を削除
